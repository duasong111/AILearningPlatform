梯度下降法原理讲解
教学 Agent
陈
请帮我解释一下梯度下降法的核心思想，以及学习率的选择有什么讲究？
AI
梯度下降法的核心思想可以类比为「下山」：

想象你站在一座山上，目标是走到最低点（损失函数最小值）。每一步你都朝最陡的下坡方向走，这就是梯度下降。

数学表达为：
θ = θ - α · ∇J(θ)

其中 α 是学习率，∇J(θ) 是损失函数关于参数的梯度。
陈
学习率太大或太小会怎么样？能用 Python 代码演示吗？
AI
好问题！学习率 α 的选择至关重要：

太大：步长过大，会在最优解附近震荡，甚至发散不收敛
太小：收敛速度极慢，训练时间过长

这是一个简单的 Python 演示：
import numpy as np def gradient_descent(learning_rate, epochs): x = 5.0 # 初始位置 # 目标函数: f(x) = x² for i in range(epochs): grad = 2 * x # 梯度 x = x - learning_rate * grad if i % 10 == 0: print(f"epoch {i}: x={x:.4f}, f(x)={x**2:.4f}") return x # 学习率 0.1 — 稳定收敛 result = gradient_descent(0.1, 50) print(f"最优解: x={result:.6f}")
建议从 0.01 或 0.001 开始尝试，配合学习率调度策略（如 warmup + cosine decay）效果更好。需要我进一步解释 Adam 优化器吗？
